## Recent verified engineering changes

- **[Prompt Injection Detector #86](https://github.com/koushikchowdary6/prompt-injection-detector/pull/86):** closed a cross-encoding evasion where printable JSON/JavaScript escapes exposed HTML entities only after the earlier decode pass. Added adversarial role-spoofing, benign and single-pass controls; both Python 3.10/3.12 post-merge jobs passed. This improves deterministic coverage, not measured external detection accuracy. [CI](https://github.com/koushikchowdary6/prompt-injection-detector/actions/runs/41505729786).
- **[Phishing URL Detector #3](https://github.com/koushikchowdary6/phishing-url-detector/pull/3):** rejects malformed URL authorities, missing hostnames and raw terminal controls before feature extraction. Batch inference continues scoring valid arguments and reports rejected positions without echoing unsafe input. A test-double contract failure was fixed before merge; post-merge tests and synthetic training smoke passed. [CI](https://github.com/koushikchowdary6/phishing-url-detector/actions/runs/41505954947).
- **[Phishing URL Detector #2](https://github.com/koushikchowdary6/phishing-url-detector/pull/2):** prevented feature-equivalent synthetic observations from crossing train/test boundaries using grouped splitting over all 14 lexical features. Tests verify group isolation, reproducible holdout counts, and explicit invalid-sample rejection. This reduces exact-vector leakage, but synthetic scores do not establish external accuracy. [Post-merge CI](https://github.com/koushikchowdary6/phishing-url-detector/actions/runs/41496852530).
- **[Security Findings Translator #21](https://github.com/koushikchowdary6/security-findings-translator/pull/21):** redacted token-only URI userinfo (not just username:password pairs) from mocked external LLM prompts and displayed results, with controls for ordinary `@` in URL paths and queries. Regex-based sanitization remains incomplete DLP. [Post-merge CI](https://github.com/koushikchowdary6/security-findings-translator/actions/runs/41496882085).
- **[Phishing URL Detector #1](https://github.com/koushikchowdary6/phishing-url-detector/pull/1):** corrected invalid IPv4 matches, missing IPv6 recognition, false DNS-subdomain counts for IP hosts, shortener lookalike domains and path/query `@` false positives. Focused tests and the synthetic training smoke test passed after merge. This improves feature semantics, not independently measured phishing accuracy. [Post-merge CI](https://github.com/koushikchowdary6/phishing-url-detector/actions/runs/41487267103).
- **[Flask AppSec Lab #34](https://github.com/koushikchowdary6/flask-appsec-lab/pull/34):** hardened note authorization against stale signed sessions after account deletion, rename or ID reassignment. Tests cover read/edit denial and malformed cookie IDs; account recreation with identical ID and username still requires server-side session revocation to address. [Python 3.10/3.12 post-merge CI](https://github.com/koushikchowdary6/flask-appsec-lab/actions/runs/41487030844).
- **[EvalForge #176](https://github.com/koushikchowdary6/EvalForge/pull/176):** rejected JSON-escaped lone Unicode surrogates in agent prompts, categories, answer references and mocked tool responses before paid model initialization. Regression tests also cover mutated in-memory datasets and valid multilingual/astral text. This protects benchmark and artifact integrity, not model quality. [Python 3.10–3.12 post-merge CI](https://github.com/koushikchowdary6/EvalForge/actions/runs/41459172461).
- **[IAM Policy Auditor #46](https://github.com/koushikchowdary6/iam-policy-auditor/pull/46):** rejected short AWS account patterns containing only fixed digits and `?`, which cannot match 12-digit account IDs; preserved valid 12-position and `*` selectors. IAM/S3 Allow/Deny, Resource/NotResource and CLI regressions passed. This is ARN shape linting, not AWS effective-permission analysis. [Python 3.10/3.12 post-merge CI](https://github.com/koushikchowdary6/iam-policy-auditor/actions/runs/41459228681).
These are tested portfolio improvements, not proof of authenticated human review, AWS effective-permission simulation, independently validated model accuracy, or production deployment.
