## Recent verified engineering changes

- **[LLM PII Redactor #28](https://github.com/koushikchowdary6/llm-pii-redactor/pull/28):** replaced repeated full-token symbol scans with one-pass frequency counting in Shannon entropy scoring. Regression tests cover hand-calculated entropy and long-token masking without disclosing secret values. [Python 3.10/3.12 post-merge checks passed](https://github.com/koushikchowdary6/llm-pii-redactor/actions/runs/41271580130). This is a CPU-work reduction for a deterministic heuristic, **not** evidence of improved detection accuracy or a guarantee of linear-time end-to-end scanning.
- **[Document Review Pipeline #7](https://github.com/koushikchowdary6/document-review-pipeline/pull/7):** refused dangling symlink bundle destinations and destinations created during staging, with regression tests verifying existing paths survive and partial staging is cleaned. [Python 3.10/3.12 post-merge CI passed](https://github.com/koushikchowdary6/document-review-pipeline/actions/runs/41271569554). The trusted single-writer assumption remains; portable atomic no-clobber directory publication is **not** claimed.
- **[EvalForge #158](https://github.com/koushikchowdary6/EvalForge/pull/158):** added unique-query-term out-of-vocabulary counts and fractions, distinguishing tokenizer-empty queries from queries whose terms are absent from the BM25 corpus. [Post-merge CI passed](https://github.com/koushikchowdary6/EvalForge/actions/runs/41268134049). These are lexical coverage diagnostics, not semantic OOD detection or independent retrieval accuracy.
- **[Prompt Injection Detector #68](https://github.com/koushikchowdary6/prompt-injection-detector/pull/68):** added bounded, prompt-free evidence for cross-label near-duplicate examples in training and holdout audits. [Post-merge CI passed](https://github.com/koushikchowdary6/prompt-injection-detector/actions/runs/41268094386). These are annotation-review warnings, not proof that labels are wrong or of independent model performance.
- **[SigmaForge #46](https://github.com/koushikchowdary6/sigmaforge/pull/46):** removed user-supplied email addresses from failed/locked-login structured logs while preserving fixed outcome codes. [All six post-merge jobs passed](https://github.com/koushikchowdary6/sigmaforge/actions/runs/41246492585). This improves telemetry privacy, not account takeover prevention.
