## Recent verified engineering changes

- **[EvalForge #175](https://github.com/koushikchowdary6/EvalForge/pull/175):** added per-question and aggregate Unicode-minus-ASCII **hit-rate** delta bounds for positive-score BM25 cutoff ties, complementing recall bounds. A zero point estimate can conceal opposite hit outcomes; these are deterministic sensitivity bounds, **not** confidence intervals or model-accuracy claims. [Python 3.10–3.12 post-merge CI](https://github.com/koushikchowdary6/EvalForge/actions/runs/41424589951).
- **[Prompt Injection Detector #84](https://github.com/koushikchowdary6/prompt-injection-detector/pull/84):** replaced unconditional `jailbreak`/`developer mode` keyword alerts with explicit activation and assistant-override patterns. Benign documentation, platform-mode questions, direct attacks, and encoded/zero-width variants have regression coverage. This is a deterministic false-positive improvement, not independently measured precision or recall. [Python 3.10/3.12 post-merge CI](https://github.com/koushikchowdary6/prompt-injection-detector/actions/runs/41433890460).
- **[EdgeWatch IoT #13](https://github.com/koushikchowdary6/edgewatch-iot/pull/13):** rejected syntactically valid telemetry when a client half-closes before its declared Content-Length, preventing persistence of incomplete HTTP frames. A loopback HTTP regression verifies the 408 response and unchanged sample count. [Python 3.10/3.12 post-merge CI](https://github.com/koushikchowdary6/edgewatch-iot/actions/runs/41421939050).
- **[SigmaForge #51](https://github.com/koushikchowdary6/sigmaforge/pull/51):** request logs now record stable FastAPI route templates rather than caller-controlled URL path segments, with a fixed sentinel for unmatched routes and pre-routing failures. Regression tests cover real router integration, sensitive dynamic identifiers, 404s, and exceptions. This limits disclosure in the request logger, not every application log. [Six-job post-merge CI](https://github.com/koushikchowdary6/sigmaforge/actions/runs/41433109372).
- **[Document Review Pipeline #11](https://github.com/koushikchowdary6/document-review-pipeline/pull/11):** rejects JSON-escaped lone Unicode surrogates before synthetic PII exact-span scoring, preserving valid astral-character offsets and honest evaluation inputs. An intermediate test-fixture failure was repaired before merge. This improves benchmark integrity, **not** measured PII recall. [Python 3.10/3.12 post-merge CI](https://github.com/koushikchowdary6/document-review-pipeline/actions/runs/41424639682).

These are tested portfolio improvements, not proof of authenticated human review, AWS effective-permission simulation, independently validated model accuracy, or production deployment.
