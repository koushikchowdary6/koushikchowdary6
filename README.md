## Recent verified engineering changes

- **[EvalForge #156](https://github.com/koushikchowdary6/EvalForge/pull/156):** added exact lower/upper evidence-only recall@k bounds across positive BM25 cutoff ties, plus per-case uncertainty and answerable-only summary aggregation. Regression tests cover mixed relevance, fixed hits, zero scores and unanswerable questions. [Python 3.10–3.12 post-merge CI passed](https://github.com/koushikchowdary6/EvalForge/actions/runs/41255170468). These bounds expose ID tie-break sensitivity, not semantic model accuracy.
- **[Prompt Injection Detector #66](https://github.com/koushikchowdary6/prompt-injection-detector/pull/66):** added opt-in fail-closed screening for feature-equivalent duplicate training rows before holdout model fitting, with CLI, policy reporting and regression tests. [Post-merge CI passed](https://github.com/koushikchowdary6/prompt-injection-detector/actions/runs/41255140760). This controls duplicate weighting, not independent data provenance.
- **[SigmaForge #46](https://github.com/koushikchowdary6/sigmaforge/pull/46):** removed user-supplied email addresses from failed/locked-login structured logs, retaining fixed outcome codes and generic 401 responses. Async regression tests verify email/password values do not reach the log record. [Post-merge CI passed all six jobs](https://github.com/koushikchowdary6/sigmaforge/actions/runs/41246492585). This improves telemetry privacy, not account takeover prevention.
- **[IAM Policy Auditor #39](https://github.com/koushikchowdary6/iam-policy-auditor/pull/39):** fixed a public-access risk misclassification: short or malformed AWS Organizations/VPC/VPC endpoint identifiers no longer downgrade wildcard-principal findings. Added regression cases for legacy/new IDs and documented format limits. [Post-merge CI passed](https://github.com/koushikchowdary6/iam-policy-auditor/actions/runs/41258853239). Format checks do not establish that an AWS resource exists or simulate effective permissions.
- **[Flask AppSec Lab #28](https://github.com/koushikchowdary6/flask-appsec-lab/pull/28):** enforced trusted loopback Host headers before secure login Origin checks, blocking attacker-controlled Host/Origin pairs and suffix spoofing while preserving localhost access. Added regression tests and retained the local-only threat model. [Post-merge CI passed](https://github.com/koushikchowdary6/flask-appsec-lab/actions/runs/41258830485). This is not permission to deploy the intentionally vulnerable demo publicly.
