## Recent verified engineering changes

- **[EvalForge #173](https://github.com/koushikchowdary6/EvalForge/pull/173):** extended the paired ASCII/Unicode BM25 audit with a four-way unanswerable lexical-match matrix and per-case Unicode-minus-ASCII deltas. This exposes offsetting retrieval tradeoffs hidden by equal aggregate counts; lexical matches are not hallucination measurements. [Python 3.10–3.12 post-merge CI](https://github.com/koushikchowdary6/EvalForge/actions/runs/41397481734).
- **[Prompt Injection Detector #82](https://github.com/koushikchowdary6/prompt-injection-detector/pull/82):** added direct system/developer instruction-override detection without requiring temporal words such as “previous,” with encoded-attack and benign controls. Repaired a CI-discovered regex-work-budget false alarm on clean maximum-length inputs. This is deterministic regression coverage, not independently measured production accuracy. [Python 3.10/3.12 post-merge CI](https://github.com/koushikchowdary6/prompt-injection-detector/actions/runs/41397727080).
- **[Security Findings Translator #20](https://github.com/koushikchowdary6/security-findings-translator/pull/20):** rejects malformed Unicode scalar values in nested security evidence before optional paid LLM requests, and sanitizes already-returned terminal text for strict UTF-8 output. [Mocked-provider CI](https://github.com/koushikchowdary6/security-findings-translator/actions/runs/41375247072).
- **[SigmaForge #50](https://github.com/koushikchowdary6/sigmaforge/pull/50):** sanitized bidi overrides/isolates, zero-width format controls, Unicode line separators and variation selectors from untrusted User-Agent telemetry before PostgreSQL persistence, with login and Unicode regression tests. [Six-job post-merge CI](https://github.com/koushikchowdary6/sigmaforge/actions/runs/41392053321).

These are tested portfolio improvements, not proof of authenticated human review, AWS effective-permission simulation, independently validated model accuracy, or production deployment.
