## Recent verified engineering changes

- **[EvalForge #164](https://github.com/koushikchowdary6/EvalForge/pull/164):** exact evidence-only MRR lower/upper bounds quantify arbitrary positive-score BM25 tie ordering, including ties entirely within the cutoff. [Python 3.10–3.12 post-merge CI](https://github.com/koushikchowdary6/EvalForge/actions/runs/41294714099). These are tie-order ranges, not statistical confidence intervals or improved model accuracy.
- **[Prompt Injection Detector #74](https://github.com/koushikchowdary6/prompt-injection-detector/pull/74):** added narrowly scoped detection for `ignore earlier instructions` and `disregard any preceding rules`, with benign contrast, encoded-input and invisible-separator regression tests. [Python 3.10/3.12 post-merge CI](https://github.com/koushikchowdary6/prompt-injection-detector/actions/runs/41299763903) passed. This expands rule coverage, not independently validated detection accuracy.
- **[Flask AppSec Lab #32](https://github.com/koushikchowdary6/flask-appsec-lab/pull/32):** extended bounded periodicity checks for operator-supplied Flask signing keys from eight to 32-character repeating blocks, with regression tests for 9-, 16- and 32-character patterns. [Python 3.10/3.12 post-merge CI](https://github.com/koushikchowdary6/flask-appsec-lab/actions/runs/41299752397) passed. These checks catch obvious weak secrets; they do not establish cryptographic entropy.
- **[IAM Policy Auditor #41](https://github.com/koushikchowdary6/iam-policy-auditor/pull/41):** added a MEDIUM warning for AWS resource-policy `Deny` + `NotPrincipal`, which AWS documents can unexpectedly deny principals with permissions boundaries. Regression tests cover ordinary Deny controls, severity thresholds, and SARIF; [Python 3.10/3.12 post-merge CI + downloadable SARIF](https://github.com/koushikchowdary6/iam-policy-auditor/actions/runs/41295264437) passed. This is a static configuration warning, not an AWS effective-access simulation.
