## Recent verified engineering changes

- **RAG benchmark integrity — [EvalForge #151](https://github.com/koushikchowdary6/EvalForge/pull/151):** audits corpus document IDs that BM25 cannot distinguish by token frequencies, flagging partially labeled relevance groups that can bias tie-broken retrieval metrics. [Python 3.10–3.12 CI passed on main](https://github.com/koushikchowdary6/EvalForge/actions/runs/41199221580). This detects lexical equivalence, not semantic duplication or model accuracy.
- **AI guardrail error slices — [Prompt Injection Detector #59](https://github.com/koushikchowdary6/prompt-injection-detector/pull/59):** adds opt-in attack-category confusion counts and false-alarm/missed-attack rates to external holdout reports, with strict input validation and no raw prompt disclosure. [Post-merge CI passed](https://github.com/koushikchowdary6/prompt-injection-detector/actions/runs/41199264392). Category labels are user-supplied; no independent holdout performance is claimed.
- **Concurrent refresh-token replay containment — [SigmaForge #44](https://github.com/koushikchowdary6/sigmaforge/pull/44):** transactional PostgreSQL token rotation and user-wide replay revocation, verified by real database concurrency tests. [Post-merge CI passed](https://github.com/koushikchowdary6/sigmaforge/actions/runs/41178777510).
- **Transactional data ingestion — [Airflow/PostgreSQL ETL #15](https://github.com/koushikchowdary6/airflow-postgres-etl/pull/15):** stage loading and fact upserts share a transaction, with rollback and overlapping-run regression tests. [Post-merge CI passed](https://github.com/koushikchowdary6/airflow-postgres-etl/actions/runs/41183092091).

These are tested engineering changes, **not** production-performance, model-accuracy, or comprehensive security guarantees.
