## Recent verified engineering changes

- **[EvalForge #162](https://github.com/koushikchowdary6/EvalForge/pull/162):** made standalone BM25 ranking reject empty/malformed corpora, duplicate document IDs and invalid queries using the same integrity checks as benchmark evaluation. [All Python 3.10–3.12 post-merge jobs passed](https://github.com/koushikchowdary6/EvalForge/actions/runs/41293115945). This hardens retrieval correctness; it does not change benchmark accuracy.
- **[Prompt Injection Detector #72](https://github.com/koushikchowdary6/prompt-injection-detector/pull/72):** replaced version-sensitive approximate row-level grouped CV with deterministic stratification of distinct TF-IDF feature groups, preserving train/test duplicate isolation and two-class fold coverage. Python 3.10 and 3.12 tests passed; [CI publishes grouped-CV JSON evidence](https://github.com/koushikchowdary6/prompt-injection-detector/actions/runs/41292269188). This improves evaluation integrity, not independently validated detection accuracy.
- **[EvalForge #161](https://github.com/koushikchowdary6/EvalForge/pull/161):** added CI-generated, downloadable ASCII/Unicode multilingual BM25 reports with matching dataset hashes, explicit tokenizer blind spots and validated lexical evidence metrics. [Python 3.10–3.12 CI and JSON artifacts passed](https://github.com/koushikchowdary6/EvalForge/actions/runs/41292243704). These use a hand-authored fixture, not an independent multilingual retrieval benchmark.
- **[IAM Policy Auditor #40](https://github.com/koushikchowdary6/iam-policy-auditor/pull/40):** added reproducible SARIF artifacts for a high-risk and least-privilege IAM example, validating severity and clean-policy contracts across Python 3.10/3.12. [Post-merge CI and SARIF artifacts passed](https://github.com/koushikchowdary6/iam-policy-auditor/actions/runs/41292248457). This is offline policy linting, not effective AWS permissions verification.
