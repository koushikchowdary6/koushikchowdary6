## Recent verified engineering changes

- **[EvalForge #178](https://github.com/koushikchowdary6/EvalForge/pull/178):** RAG embedding responses now reject explicit model-identity mismatches and non-integer result indices before cache writes, preventing incompatible vectors from contaminating model-scoped retrieval benchmarks. Offline regression tests and Python 3.10–3.12 passed after merge. [CI](https://github.com/koushikchowdary6/EvalForge/actions/runs/41541257385).
- **[Document Review Pipeline #13](https://github.com/koushikchowdary6/document-review-pipeline/pull/13):** synthetic PII evaluation reports are staged and fsynced before exclusive atomic publication; interrupted writes cannot leave partial final reports, and existing reports are not overwritten. Failure, symlink and replay tests passed on Python 3.10/3.12. This is artifact integrity, not improved PII detection accuracy. [CI](https://github.com/koushikchowdary6/document-review-pipeline/actions/runs/41541426726).
- **[SigmaForge #53](https://github.com/koushikchowdary6/sigmaforge/pull/53):** Starlette's outer error middleware can bypass inner response-header middleware on unhandled exceptions. A shared policy now applies `no-store`, CSP and other security headers to generic 500s as well as normal API responses. ASGI regression and all six post-merge CI jobs passed. [CI](https://github.com/koushikchowdary6/sigmaforge/actions/runs/41533396409).
- **[Security Findings Translator #22](https://github.com/koushikchowdary6/security-findings-translator/pull/22):** bidirectional format controls could split recognizable credential names before redaction in outbound LLM evidence or displayed results. Sanitization now removes those controls before secret matching, with signed-URL, unsafe-key and multilingual regressions. Regex-based detection remains incomplete DLP. [Post-merge CI](https://github.com/koushikchowdary6/security-findings-translator/actions/runs/41533534091).
- **[EvalForge #177](https://github.com/koushikchowdary6/EvalForge/pull/177):** canonical Unicode category labels now prevent invisible, padded and mixed-script lookalikes from silently excluding agent safety cases from evaluation denominators. Valid multilingual labels remain supported; offline regressions and Python 3.10–3.12 passed after merge. [CI](https://github.com/koushikchowdary6/EvalForge/actions/runs/41524555790).
- **[Document Review Pipeline #12](https://github.com/koushikchowdary6/document-review-pipeline/pull/12):** the synthetic PII evaluator now rejects detector findings whose reported extracted value differs from the original-text span. Forged/empty values cannot earn exact-span credit; Unicode-offset controls pass. This is benchmark-integrity work, not independent PII detection accuracy. [Post-merge CI](https://github.com/koushikchowdary6/document-review-pipeline/actions/runs/41515510298).
- **[EdgeWatch IoT #14](https://github.com/koushikchowdary6/edgewatch-iot/pull/14):** optional replay quarantine now requires the receiver's bounded JSON error contract, rather than trusting any HTTP 400/413 from an intermediary. Proxy and malformed responses retain queued events; valid permanent receiver rejections remain quarantinable. This is not cryptographic receiver authentication. [Post-merge CI](https://github.com/koushikchowdary6/edgewatch-iot/actions/runs/41515435455).
- **[Prompt Injection Detector #86](https://github.com/koushikchowdary6/prompt-injection-detector/pull/86):** closed a cross-encoding evasion where printable JSON/JavaScript escapes exposed HTML entities only after the earlier decode pass. Added adversarial role-spoofing, benign and single-pass controls; both Python 3.10/3.12 post-merge jobs passed. This improves deterministic coverage, not measured external detection accuracy. [CI](https://github.com/koushikchowdary6/prompt-injection-detector/actions/runs/41505729786).

These are tested portfolio improvements, not proof of authenticated human review, AWS effective-permission simulation, independently validated model accuracy, or production deployment.
